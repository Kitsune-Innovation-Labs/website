# Kitsunebi Living Styleguide — Legacy Snapshot

This directory preserves the retired pre-Lab Kitsunebi build for historical review.

It is the former **Living Neumorphism / Living Styleguide** implementation that was active before the current Kitsunebi Lab replaced `/design/`. The snapshot was preserved from the GitHub Pages deployment based on commit `0968d591915739577a7e849b1a02bd679a4d8ec0` (`Initial Migration`).

This archive is intentionally retained as design provenance: it is useful for comparing the evolution of Kitsunebi, revisiting earlier interaction ideas, and documenting why later decisions changed. It is not the active design system and is not included in the Pages deployment.

The archived `index.html` uses relative asset paths so it can be opened from this directory if checked out locally.
