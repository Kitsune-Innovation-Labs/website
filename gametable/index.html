What GameTable is for

A game library that belongs to you.

GameTable brings self-hosted game distribution, metadata, profiles and launch workflows together without asking you to hand ownership of the experience back to a commercial launcher.

▣

One library

Organise DRM-free PC games and ROMs behind one clean library instead of scattering them across folders, shares and launchers.

↓

Download & launch

GameTable Desktop downloads managed games from your Server and launches native Linux titles or Windows games through umu/Proton where appropriate.

⌂

Self-hosted

Your Server, database and game files stay on infrastructure you control. GameTable is built around local ownership and a Linux-first deployment model.

Server + Desktop

One platform.
Two clear jobs.

GameTable keeps hosting and play separate on purpose. The Server owns the library and delivery; Desktop owns the local download and launch experience.

GameTable Server

Host the library.

A single self-contained service provides the web experience, API, profiles, metadata, game files and ROM catalogue.

  • Rust + Axum backend
  • Bundled web interface
  • SQLite persistence
  • PC games + ROM libraries
GameTable Desktop

Play the games.

The native client handles downloads, installation state and launching on the machine where you actually play.

  • Resumable downloads
  • SHA-256 verification when available
  • Native Linux launching
  • Windows games through umu-run / Proton
The philosophy

Host the library.
Own the games.
Let GameTable handle the rest.

GameTable is built for collections you can keep, move, back up and understand. It does not try to become the owner of your games; it gives your own library a first-class home.

Where it is going

More than a launcher.

Some parts of the broader GameTable vision are intentionally still in development. We would rather label the roadmap honestly than pretend planned features have already shipped.

One Server container.

The current GameTable Server packages the Rust API and generated web interface together. Mount your persistent configuration and libraries, expose the web port, and keep the data outside the container so upgrades stay boring.

GameTable is currently in active development. The source repository is not yet public, while the Server container is published for deployment and testing.
