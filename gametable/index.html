Server + Desktop

One platform.
Two clear jobs.

Server hosts the library. Desktop handles downloads and play.

GameTable Server

Host the library.

The server provides the web experience, profiles, metadata and your game catalogue.

  • Web interface + API
  • PC games + ROMs
  • Simple persistent storage
GameTable Desktop

Play the games.

The desktop app downloads, tracks and launches games on your machine.

  • Resumable downloads
  • Native Linux launching
  • Windows games through Proton
The philosophy

Host the library.
Own the games.

GameTable gives the games you already own a first-class home, without making a storefront the centre of the experience.
