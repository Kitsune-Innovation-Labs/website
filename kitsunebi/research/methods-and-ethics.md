# Study Protocol and Ethics Checklist — Draft

**No participants have been enrolled; no ethics approval claimed.**

## Aim and scope

Evaluate whether user-authored Kitsunebi expression improves ownership and comfort without degrading task completion, discoverability, accessibility and safety compared with suitable baselines.

## Before recruiting

1. Seek institutional/community ethics review where applicable. Separate product testing from research intended for publication.
2. Draft plain-language consent, withdrawal procedure, confidentiality plan and inclusive compensation policy.
3. Decide which metrics are necessary, who can access raw data and deletion schedule; collect no account passwords or diagnostic medical history.
4. Offer participation by keyboard, pointer, touch, screen reader or alternative communication without requiring disclosure of diagnoses.
5. Pre-register hypotheses, primary endpoints, sample rationale, non-inferiority margins if used, planned subgroup analyses and stopping rules.
6. Include assistive-technology and accessibility experts; consult on Māori data stewardship if collecting relevant community data.

## Study matrix

| Variable | Conditions |
| --- | --- |
| Experience | Linux newcomer / experienced user (reported, not inferred) |
| Interaction | keyboard / mouse / touch / assistive technology as relevant |
| Voice | reference / sanctuary / workshop / playground / self-authored |
| Comfort | reduced motion, high-contrast / standard, text scaling |
| Platform | Web demo initially; desktop / TV after actual implementations |

Use counterbalancing to reduce task-order effects, equivalent tasks in each condition, and baseline training equal across conditions.

## Tasks

- Find and close a window without prior knowledge (demonstrates discoverability; Niri experiences inspired the question).
- Identify and reverse a dangerous action.
- Change density and motion independently, then explain the effective settings.
- Export and import a voice profile; check whether meaning survived.
- Navigate a dialog with keyboard only and report focus visibility.
- Repeat selected tasks with reduced motion / forced colours / increased text scaling.

## Outcomes and analysis plan

Primary: first-attempt success on common actions and critical-error rate. Secondary: time, correction attempts, subjective ownership, comfort, workload and preference after familiarisation. Report raw denominators, uncertainty and failures. Do not assert medical outcomes. Link anonymised materials where consent permits.

## Safeguards

No default telemetry; test credentials; privacy-preserving screen recordings only if explicitly consented; participants can stop at any time; no grading or employment impact; avoid recruiting one's own students without independent ethical protections. Destroy identifiable raw data on the communicated timetable. Report accessibility issues even if they invalidate the original hypothesis.

## Publication gate

Distinguish peer review from repository review. Use reproducible snapshots of stimuli, code versions, preregistration link and honest dataset limitations. Never write results before running the study.
